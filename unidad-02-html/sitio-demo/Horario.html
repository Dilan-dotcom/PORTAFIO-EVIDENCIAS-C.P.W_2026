Como entregar una practica con listas ordenadas

  1. Traer los cambios con git pull
  2. Crear la rama de la practica con git check out o switch -c
  3. Trabajar y hacer commits atomicos(mensajes apropiados)
  4. Subir la rama con git push
  5. Abrir el pull request en git hub
  6. Revisar y fusionar el pull request
  7. Volver a la rama principal-main
  8. Eliminar rama de la practica

Glosario Git con listas descriptivas

Commit
Instantanea permanente del proyecto en un momento dado
Rama
Linea de trabajo paralela que no afecta a main
Pull
Solicitud de revision para incorporar una rama
